Part 1 · Find the loop

What is being observed and changed?

A building uses a thermostat to keep a classroom near 70°F. The room is currently 64°F. The thermostat measures the room and turns on the heat.

Part 2 · Error and correction

Run a feedback loop by hand

Use target \(r=70\), starting state \(x_0=64\), and response strength \(k=0.5\).

error = target − observed,    next state = current state + k(error)
Part 3 · Response strength

Slow correction or overshoot?

Two systems both have target 100 and start at 80.

System A: \(k=0.25\)

System B: \(k=1.5\)

Part 4 · Positive feedback

When a change produces more change

An online post begins with 100 views. Suppose each round increases exposure by 20%.

next exposure = 1.20 × current exposure
Part 5 · Learning from error

A tiny adaptive loop

A simple predictor uses an adjustable weight \(w\). Its prediction is twice the weight. The target is 6. After each attempt, use:

error = target − prediction,    new weight = old weight + 0.25(error)

Start with \(w=1\).

Modern neural-network training is vastly larger, but the recognizable loop remains: attempt → measure error → change adjustable weights → attempt again.
