2Degree, the handshake rule, and density

Degree measures immediate connectivity. Start locally, then use those local counts to check the network globally.

The network has 9 edges. Since every edge contributes 2 to the total degree, the handshake rule predicts a degree sum of 2(9)=18.

There are 7(6)/2=21 possible undirected edges among seven nodes. Density is actual edges divided by possible edges.

3Paths and network distance

A path is a sequence of adjacent edges. Distance means the length of a shortest path. Multiple shortest paths can exist.

Interpretation: if a message can cross one edge per round, distance gives the earliest round in which a node can possibly receive it.

4Centrality is not one idea

Different meanings of “central” answer different questions. A node can have many neighbors, be only a few steps from everyone, or sit between otherwise separated groups.

6Diffusion over several rounds

Now treat the network as a communication system. A is informed at round 0. During each round, every informed node sends the message to all of its neighbors. Once informed, a node stays informed.

Round 0: only A is informed.

Notice the geometry: nodes arrive in layers of shortest-path distance from A. Structure constrains the earliest possible spread even before we model human behavior.

7Thresholds and collective behavior

Automatic spreading is only one model. Suppose instead that a node adopts a behavior when at least half of its neighbors have already adopted it.

Node E has three neighbors: D, F, and G. “At least half” means E needs at least 2 active neighbors.
