# Math 107 module printables

Each student PDF contains the module summary, prequiz, and closely matched quiz. The problems use complete contexts and leave open space for written work rather than answer lines.

Student files are in `materials/modules/`. Matching worked instructor keys are in `materials/instructor_keys/`.

The course module cards link only to the student PDFs.

- Module 1: Number Systems
- Module 2: Frequency, Probability, and Distributions
- Module 3: Basic Statistics
- Module 4: Intermediate Statistics and Inference
- Module 5: Basic Computer and Information Theory
- Module 6: Interest and Loans
- Module 7: Cost, Revenue, and Profit
- Module 8: Convex Geometry
- Module 9: Linear Programming
- Module 10: Fractal Geometry and the Limits of Prediction
