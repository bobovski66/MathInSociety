AI Application — Signals Through a Neural Network

Represent a simplified neural network as nodes connected by weighted edges, then trace how a signal moves.

A small signal network

Two input nodes send values to a hidden node:

Input A = 2, weight A→H = 0.5
Input B = 4, weight B→H = 0.25
Hidden signal: (2(0.5)+4(0.25)=2)

From H, a connection of weight 3 sends the signal to output O. In this simplified example, O receives (2 imes3=6).

Think about the network

  1. Which inputs are directly connected to H?
  2. What changes if one input link is removed?
  3. Why is this diagram only a simplified model of an AI system? Consider layers, many weights, data, and training.
  4. Where might feedback enter during training?

A graph captures connectivity; weights describe the strength and direction of influence in this model.
