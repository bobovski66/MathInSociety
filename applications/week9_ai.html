AI Application — Signals Through a Neural Network

A neural network is literally a network: numbers move through directed links, and edge weights determine how strongly one node influences another.

Start with the graph idea

In the rest of Module 9, an edge often meant “a message can travel between these two places.” A neural-network edge carries a numerical signal instead. It is also directed and weighted.

Node

A location where numerical information is collected and transformed.

Directed edge

A route along which a signal travels in one direction during a forward pass.

Weight

A multiplier that changes the size and sign of the signal sent along an edge.

Important: this tiny network is a teaching model, not a realistic modern language model. Real systems contain many layers, enormous numbers of weights, nonlinear operations, and specialized structures such as attention.

1 · A two-layer signal network

Use input values x₁ = 2 and x₂ = 4. Each hidden node adds its incoming weighted signals.

H₁ = 0.50x₁ + 0.25x₂ = 0.50(2) + 0.25(4) = 2
H₂ = −0.50x₁ + 0.75x₂ = −0.50(2) + 0.75(4) = 2
O = 1.50H₁ − 0.50H₂ = 1.50(2) − 0.50(2) = 2

The network turns the input vector (2,4) into output 2 by repeatedly combining weighted signals.

4 · Remove one connection

Suppose the edge from x₂ to H₁ disappears. With the original inputs x₁=2 and x₂=4, H₁ would now receive only 0.50(2)=1. H₂ is unchanged at 2.

New O = 1.50(1) − 0.50(2) = 0.5

One removed edge changed the output from 2 to 0.5. In a weighted network, an edge can matter because of both where it leads and how strongly it acts.

5 · Connectivity is not enough

In the community-alert example, edges were essentially yes/no. Neural-network links carry signed weights. Compare these possibilities:

weight = 0

The edge has no numerical effect even if it is drawn.

large positive weight

A positive input strongly increases the receiving node's sum.

negative weight

A positive input decreases the receiving node's sum.

This is why an unweighted graph captures only the architecture. The weights contain much of what the trained model has learned.

6 · Where feedback enters: training

A forward pass moves signals from inputs toward an output. Training closes a feedback loop around that process.

inputs → prediction → compare with target → error → adjust weights → next prediction

Suppose this network predicts O=2, but the desired target for this training example is 3. Using the simple error convention

error = target − prediction,

This links Module 9 back to Module 5. The network specifies the routes of influence. The training feedback loop uses error to change the weights on those routes. Backpropagation is the mathematical machinery that assigns responsibility for error through the network so the weights can be updated.

7 · The larger idea

There are now three levels of description:

Structure

Which nodes are connected? Which paths are possible?

State and signal

What numerical values are present right now, and how do weights transform them?

Learning dynamics

How do repeated errors change the weights and therefore future signal flow?

That progression—structure → dynamics → feedback—is one of the main reasons network mathematics appears across AI, ecology, economics, communication, and social systems.
