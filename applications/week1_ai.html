Module 1: AI Application — How Text Becomes a Number Sequence

Sequences and recursion give us a first mathematical foothold on language models.

A question for this module
How can a sentence become something a computer can do mathematics with?

You have already worked with ordered lists of numbers. That turns out to be a useful place to begin. A language model cannot work directly with a sentence as an idea; it needs a numerical representation of the text.

Start with familiar mathematics

The Module 1 idea

An arithmetic sequence such as \[ 5,8,11,14,\ldots \] has two features that matter here. First, the entries are ordered. Second, a rule can tell us how the sequence grows. If \(a_0=5\), then \[ a_n=5+3n \] and also \[ a_{n+1}=a_n+3. \] The second equation is recursive: the next term is built from the current term.
Now put that mathematics to work

The AI connection

Text can also be turned into an ordered sequence. A language model first breaks text into pieces called tokens. A token might be a whole word, part of a word, or punctuation. Each token is assigned an integer label called a token ID. Here is a tiny invented vocabulary. It is listed by token ID so you can see that the ID numbers themselves have nothing to do with sentence order.
Token IDToken
8on
17sat
42cat
55the
91mat
103slept
The sequence \[ (42,17,8,55,91) \] therefore means “cat sat on the mat.” The sentence decides the order. The numbers are just labels.
Keep the scale in perspective. These numbers are deliberately small so the calculation is visible. A real LLM uses a much larger vocabulary, high-dimensional vectors, and many repeated layers. We are isolating one genuine mathematical structure at a time.

The length of the text is now an arithmetic sequence: \[ L_n=4+n, \] or recursively, \[ L_{n+1}=L_n+1. \] Notice what is—and is not—following the arithmetic pattern. The number of tokens increases by 1. The token IDs themselves can jump anywhere in the vocabulary.
