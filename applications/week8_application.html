Application — Workshop Production Region

Use two resource constraints to find every possible production corner, test candidate plans, and compare a linear profit expression at the vertices.

How to complete this application

  1. Translate wood and production limits into inequalities before finding any corner.
  2. Test proposed production plans against every constraint.
  3. Evaluate profit only at feasible vertices and report the production plan as well as the dollar value.

Math model

Feasible means satisfying every constraint. For a bounded convex polygon and a linear objective, the maximum or minimum occurs at a vertex.

Context

Chairs and tables

A small workshop makes chairs and tables. Let x be the number of chairs produced in a week and y the number of tables.

Wood limit

Each chair uses 2 units of wood and each table uses 4 units. At most 40 units are available.

2x + 4y ≤ 40

Labor limit

Each item requires one production slot, and at most 14 slots are available.

x + y ≤ 14

Because negative production is impossible, also require x ≥ 0 and y ≥ 0. Each chair contributes $30 toward weekly profit and each table contributes $50, so

P = 30x + 50y.
