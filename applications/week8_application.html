Module 8 · Graph Theory and Networks

One connection, a stronger community

A decision exercise about resilience, routes, and the limits of a mathematical model.

Decision: The county has funding for exactly one new two-way communication contact. Its main goal is to keep the shelter and community center reachable from the emergency coordinator if D–E fails.

See the current network

The existing contacts are AB, AC, BC, BD, CD, DE, EF, EG, FG. Assume each one is a reliable two-way channel until a specified failure occurs. Your recommendation must use the network, not merely how close the dots appear.

Compare two proposals

Proposal A: add A–D

Shortens A's route to the school. Cost: one contact.

Proposal B: add D–F

Creates a second route between the regions. Cost: one contact.

Work through the decision

1. Present routes: Before any new edge, find a path from A to G and count its links.
2. Test the failure: Remove D–E from the original network. Which locations can the coordinator still reach? Which cannot be reached?
3. Compare proposals: For each proposal, test the same D–E failure. Which one meets the county's goal? Give an actual route showing that the proposed network remains connected.
4. Consider a different failure: Would your recommendation still work if the school D went offline entirely? Explain the difference between an edge failing and a node failing.

Write a short recommendation

Your decision memo can be one paragraph: recommend one link, support the decision with a route or component count, and name one real-world detail that the model leaves out (for example, cost to maintain, accessibility, communication reliability, or trust).

A network model can establish whether a route exists under its rules. It does not by itself establish what a community should value most.
