Step 1 · Module 10 mathematics

A recursive rule uses the current state to create the next state

In Module 10, you study recursions such as \[ x_{n+1}=rx_n(1-x_n). \] The current value \(x_n\) is used to calculate the next value \(x_{n+1}\). Repeating the rule creates a trajectory. You also saw that long-term behavior can become hard to predict when small differences are repeatedly carried forward.
Step 2 · Make the AI connection

An LLM is also built around a repeated next-step rule

A language model generates one token, appends it to the text, and then uses the new text to calculate another next-token probability distribution. This is called autoregressive generation. There is an important difference from the deterministic logistic-map examples: language generation commonly includes probability sampling. So the next state depends both on the current context and on which possible token is selected.

Keep the scale in perspective: this page uses tiny numbers so you can see the mathematics. Real language models use many-dimensional vectors, very large vocabularies, and many repeated layers. The simplified calculation is a model of one mathematical structure, not a miniature copy of the whole system.

Step 3 · Worked example

Watch one early branch change the next problem

Suppose the current prompt is:
“The light in the forest was …”
and the next-token distribution is \[ P(\text{moving})=.45,\quad P(\text{flickering})=.35,\quad P(\text{Venus})=.20. \] If “moving” is selected, the new context ends with “was moving,” and the model computes a new distribution from that context. If “Venus” is selected instead, the new context ends with “was Venus,” and the next distribution is generally different. So one branch changes the input to every later step. The model does not generate the whole paragraph first and then reveal it; generation unfolds recursively.
New vocabulary

Name the ideas after seeing the mathematics

These terms describe structures you have already used above.

autoregressiveEach new generated item is conditioned on the sequence already generated.
trajectoryOne complete path through successive generated states.
branchingDifferent possible next tokens lead to different future contexts.
hallucinationFluent output that contains unsupported or false content. High linguistic probability is not the same thing as factual truth.
