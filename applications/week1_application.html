Week 1 Application — Two Growth Models

Compare a fixed-increase model with a fixed-percentage model used to forecast monthly housing demand.

How to complete this application

  1. Read both update rules in words before filling the table.
  2. Compute the first few months from the recursions, then identify constant difference versus constant ratio.
  3. Use the month-12 forecast to compare what fixed addition and fixed percentage growth actually do.

Math model

\(A_{n+1}=A_n+120\) adds the same number of households each month. \(B_{n+1}=1.06B_n\) multiplies the current number by the same factor each month.

Context

A town planning office is comparing two simple forecasts for the number of households needing service. Both forecasts begin with 2,000 households at month 0.

The planners know these are simplified models. The purpose is to see how two different update rules produce different long-term behavior.

Model A: fixed increase

The town adds about 120 households each month.

A₀ = 2000,   Aₙ₊₁ = Aₙ + 120

The same amount is added each month.

Model B: percentage growth

The number of households grows by 6% of the current total each month.

B₀ = 2000,   Bₙ₊₁ = 1.06Bₙ

The amount added changes because 6% is taken from the current value.

Investigation

For each model, month 0 is the starting value. Month 1 is found by applying the update rule once.

This comparison is why the update rule matters: a fixed percentage eventually produces larger absolute monthly increases than a fixed addition.
