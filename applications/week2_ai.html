Week 2 / AI application

Choosing a next token

Use a small probability distribution to understand complements, sampling, and expected counts in text generation.

Four possible continuationsRepeated drawsProbability and meaning

Several continuations can be possible

Read the unfinished sentence: The cat slept on the … You might finish it with “bed,” “sofa,” or “floor.” A language model can assign different probabilities to possible next pieces of text.

A token is a piece of text used by the model. It may be a word, part of a word, or punctuation. Here each listed word stands for one token so we can calculate by hand.

Our model has just four possible next tokens. The numbers are invented for this example; they are not measurements from a particular AI system.

Next tokenProbabilityEquivalent share
bed.5050%
sofa.2525%
floor.2020%
moon.055%

All four probabilities are nonnegative and add to 1. This is a probability distribution of the same kind used for a spinner. The token with the largest probability is favored; it is not the only possible draw.

Sampling means making a draw according to the probabilities

Imagine dividing a strip of length 1 into four intervals. A randomly chosen number from 0 up to 1 lands in one interval. Wider intervals are more likely to be hit.

Use the familiar rules

P(not bed) = 1 − 0.50 = 0.50. Across 200 independent draws from this fixed distribution, the expected number of sofa selections is 200 × 0.25 = 50. An actual run can produce a different count.

Some generation rules always choose a most probable token. The experiment below uses sampling, which allows different continuations from the same fixed probabilities.

What does a high token probability tell us?

It describes the model’s distribution over possible continuations in that context. It is not a probability that the resulting sentence is factually true. A model can assign high probability to an incorrect continuation.
