Module 2: AI Application — Next-Token Probability

Probability distributions, sampling, and why the same prompt can produce different answers.

Why this page exists

Mathematics gives us a way into AI

At each generation step, an LLM assigns possible next tokens different numerical scores. Those scores are converted into a probability distribution. A larger probability means the token is more likely to be selected, not that it is guaranteed.

Important: the examples on this page are intentionally tiny models. Real LLMs use huge vectors, many layers, and billions of learned numerical parameters. We simplify the scale while keeping the mathematical structure recognizable.

AI vocabulary

Four ideas to carry with you

next-token distributionA list of possible next tokens and their probabilities.
samplingUsing probabilities to select an outcome.
temperatureA setting that can make a distribution more concentrated or more spread out.
deterministic choiceAlways taking the highest-probability token; useful in some settings but not the only way models generate.
Worked example

Follow the numbers

Suppose the prompt is “The cat slept on the …” and a toy model gives: \[ P(\text{bed})=.50,\quad P(\text{sofa})=.25,\quad P(\text{floor})=.20,\quad P(\text{moon})=.05. \] The probabilities add to 1. If we generated many times from exactly this distribution, “bed” would appear about half the time in the long run, but any single generation could select another token.
Investigation

Try the mathematics yourself

1. For probabilities 0.50, 0.25, 0.20, and 0.05, what is their total?

2. What is the probability that the next token is NOT “bed”?

3. In 200 independent generations, about how many would you expect to choose “sofa” if its probability stays 0.25?

4. Which distribution is more concentrated?

What to remember

AI idea of the week

An LLM's next word is better understood as a random variable drawn from a changing probability distribution. The distribution changes after every generated token because the context changes.

You do not need to know every engineering detail of an LLM to reason mathematically about what it is doing. We will keep adding one mathematical layer at a time.
