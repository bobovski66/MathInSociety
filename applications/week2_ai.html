Module 2: AI Application — Next-Token Probability

The probability distributions from Module 2 become a model for choosing what comes next.

A question for this module
If several words could reasonably come next, how can a model choose among them?

A sentence usually has more than one possible continuation. “The cat slept on the …” could end with “bed,” “sofa,” “floor,” or something much stranger. Probability gives us a way to describe that uncertainty without pretending there is only one possible continuation.

Start with familiar mathematics

The Module 2 idea

In Module 2, you turned counts into relative frequencies and recognized probability distributions. If 100 observations fall into four categories with counts \[ 50,25,20,5, \] then their relative frequencies are \[ 0.50,0.25,0.20,0.05. \] Because the values are nonnegative and add to 1, they form a probability distribution.
Now put that mathematics to work

The AI connection

For a language model, the categories can be possible next tokens. Suppose the current text is:
The cat slept on the …
A tiny model might assign:
Possible next tokenProbability
bed0.50
sofa0.25
floor0.20
moon0.05
This is exactly the kind of mathematical object you studied in Module 2. The model can sample from the distribution: “bed” is favored, but another token can still be selected.
Keep the scale in perspective. These numbers are deliberately small so the calculation is visible. A real LLM uses a much larger vocabulary, high-dimensional vectors, and many repeated layers. We are isolating one genuine mathematical structure at a time.
Follow one example

Work through the calculation

The same probability rules apply immediately. Since \[ P(\text{bed})=0.50, \] the complement rule gives \[ P(\text{not bed})=1-0.50=0.50. \] If the same distribution were sampled independently 200 times, the expected number of “sofa” selections would be \[ 200(0.25)=50. \] That does not mean every group of 200 generations must contain exactly 50 sofas. It means 50 is the long-run expected count.

Where this leaves us
The next piece of the LLM story is therefore \[ \text{current text}\longrightarrow\text{a probability distribution for the next token}. \] A model is not usually consulting a hidden completed sentence. At each step, it is assigning different amounts of probability to different possible continuations.
