Week 5 Application — Keeping a Community Greenhouse Stable

Use a simple feedback rule to decide how aggressively a greenhouse controller should respond to temperature changes.

Context

A controller that can be too timid or too aggressive

A community greenhouse should stay near 72°F. At dawn the temperature is 64°F. A sensor measures the temperature every hour. The heating system uses the difference between the target and the measured temperature to decide how much correction to make.

error = 72 − measured temperature
next temperature = current temperature + k(error)

The number \(k\) is the response strength. A larger \(k\) means a stronger correction.

Compare two settings

Setting A and Setting B

Setting A: \(k=0.50\)

Setting B: \(k=1.50\)

Delayed information

Now the sensor report arrives one hour late

Suppose the controller is at 74°F now, but the newest sensor value it has received is still 68°F. With \(k=0.50\), it acts on the old measurement.

The controller is trying to fix a situation that no longer exists. This is one reason delay can produce overshoot.

Decision

Recommend a setting

Why this matters

A greenhouse is only one example. Similar questions arise when a person adjusts steering, a store adjusts inventory, a body regulates temperature or glucose, or an organization responds to measurements. The arithmetic changes from case to case, but the structure remains: observe → compare → act → observe again.
