Week 5 Application — When the Greenhouse Responds to Yesterday

Use recursive sequences to make a practical decision about a greenhouse controller that receives information one step late.

Identify the cybernetic system

Cybernetics is the study of communication, feedback, and control. In this example, the state is the greenhouse temperature; a thermometer is the sensor; 70°F is the reference; the thermostat is the controller; and the heater or fan is the actuator. Its action changes what will be measured next.

The goal is regulation through corrective (negative) feedback. But as you will see, correcting an old reading can cause overshoot despite that goal.

A familiar greenhouse problem

The greenhouse starts at 64°F and the desired temperature is 70°F. Each hour, a simple controller changes the temperature by half of the observed difference from the target.

In the first arrangement, the thermometer reports the current temperature immediately. In the second arrangement, the report is one hour old. We will use the same mathematical model for both systems so that the delay is the only difference.

Immediate: next = current + 0.5(70 − current).

Delayed: next = current + 0.5(70 − temperature from one step earlier). To begin the delayed sequence, assume the temperature was 64°F in the hour before step 0.

Follow the two sequences

Work from one step to the next. Each new value becomes the starting value for the following calculation. Do not replace the delayed reading with the current temperature.

Immediate measurement

Start \(x_0=64\); use the current reading.

One-step-old measurement

Start \(x_{-1}=x_0=64\); use the previous reading.

Worked reminder: In the delayed system, the reading used to calculate \(x_2\) is still \(x_0=64\), not \(x_1=67\).

What the graph is telling us

At step 3, the immediate controller has not yet reached the target, but the delayed one has passed it. The delayed controller used the old 67°F report when the actual temperature was already 70°F, so it added more heat.

Question A

If the goal is to approach 70°F without crossing it, which of these settings works better over the first few rounds?

Question B

If the delayed system is now at 71.5°F but the available reading is still 70°F, what correction will it make this round?

Where statistics enters the decision

In reality, the sensor may also be noisy. Taking the average of several measurements could reduce random variation, but it may take extra time. More precise measurements and faster feedback are not always the same thing.

As you decide how a greenhouse should operate, ask whether measurements are reliable enough to trust, and whether they arrive in time for useful action. Our model is intentionally simple: actual heating equipment responds gradually and weather can change the temperature independently.
