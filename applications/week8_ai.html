Step 1 · Module 8 mathematics

A convex combination stays between the points

In Module 8, a convex combination uses nonnegative weights that add to 1. For two points \(A\) and \(B\), \[ P=wA+(1-w)B,\qquad 0\le w\le1, \] lies on the line segment joining \(A\) and \(B\). For more points, convex combinations fill the convex hull: the smallest convex region containing those points.
Step 2 · Make the AI connection

Attention weights have exactly this form

In Module 3 we used attention weights such as \[ 0.10,0.20,0.60,0.10. \] They were nonnegative and added to 1. That means the weighted result was not only a statistical weighted average—it was also a convex combination. To see the geometry, imagine a very simplified model where tokens are represented by points in a two-dimensional plane. Real token representations use many more coordinates, but two dimensions let us draw and calculate.

Keep the scale in perspective: this page uses tiny numbers so you can see the mathematics. Real language models use many-dimensional vectors, very large vocabularies, and many repeated layers. The simplified calculation is a model of one mathematical structure, not a miniature copy of the whole system.

Step 3 · Worked example

Combine two toy token embeddings

Let \[ A=(2,1),\qquad B=(8,5). \] Use weights 0.75 and 0.25: \[ P=0.75A+0.25B. \] Coordinate by coordinate, \[ x=0.75(2)+0.25(8)=3.5, \] \[ y=0.75(1)+0.25(5)=2. \] So \[ P=(3.5,2). \] Because the weights are nonnegative and add to 1, this point lies on the segment from \(A\) to \(B\).
