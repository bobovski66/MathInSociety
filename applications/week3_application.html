Week 3 Application — Choosing a Filling Machine

Use center and spread to compare two machines that are both aimed at the same 250 mL target.

How to complete this application

  1. Compute mean, range, and standard deviation for both machines.
  2. Use the 250 mL target to judge center and the spread measures to judge consistency.
  3. Apply the stated 246–254 mL process rule before choosing a machine.

Math model

Mean measures center. Range and standard deviation measure spread. This course uses \(s=\sqrt{\frac1n\sum(x_i-\bar x)^2}\).

Context

Same target, different consistency

A beverage company is testing two filling machines. Each machine is set to dispense 250 mL into a bottle. Engineers sample five bottles from each machine.

Model

The statistics we will use

Center

The mean tells us whether a machine is centered near the 250 mL target.

mean = (sum of fills) / n

Spread

The range and standard deviation measure bottle-to-bottle variability.

SD = √[(Σ(x − mean)²) / n]

Use the Chapter 3 convention and divide by n.
