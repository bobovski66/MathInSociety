Step 1 · Module 3 mathematics

An ordinary mean gives every value equal influence

In Module 3 you compare measures of center. For four values \(2,5,8,10\), the ordinary mean is \[ \bar x=\frac{2+5+8+10}{4}=6.25. \] This can also be written as \[ 0.25(2)+0.25(5)+0.25(8)+0.25(10)=6.25. \] Writing the mean this way reveals that an ordinary mean is a weighted average with equal weights.
Step 2 · Make the AI connection

Attention changes the weights

In a transformer, the model does not have to treat every earlier token equally. For a particular calculation, some earlier pieces of context can receive larger attention weights than others. We will simplify each token down to just one numerical feature. Suppose four earlier tokens have feature values \[ 2,;5,;8,;10 \] and receive attention weights \[ 0.10,;0.20,;0.60,;0.10. \] The weights are nonnegative and add to 1, just like probabilities. The attention calculation forms a weighted combination instead of an ordinary mean.

Keep the scale in perspective: this page uses tiny numbers so you can see the mathematics. Real language models use many-dimensional vectors, very large vocabularies, and many repeated layers. The simplified calculation is a model of one mathematical structure, not a miniature copy of the whole system.

Step 3 · Worked example

Calculate the weighted average

Compute \[ 0.10(2)+0.20(5)+0.60(8)+0.10(10). \] Term by term, \[ 0.20+1.00+4.80+1.00=7.00. \] So the weighted result is 7. The feature value 8 has especially strong influence because it received the largest weight, 0.60. A real transformer performs this idea with vectors containing many coordinates, not with one number. But weighted combination is the mathematical idea to keep.
