Step 1 · Module 3 mathematics

The ordinary mean gives equal weight

For the four values

\[2,5,8,10,\]

the mean is

\[\frac{2+5+8+10}{4}=6.25.\]

We can write the same calculation as

\[0.25(2)+0.25(5)+0.25(8)+0.25(10)=6.25.\]

So an ordinary mean is a weighted average with four equal weights.

Step 2 · Make the AI connection

Now let some values count more than others

Use the weights

\[0.10,0.20,0.60,0.10.\]

They add to 1, but the third value receives much more weight. The weighted average is

\[0.10(2)+0.20(5)+0.60(8)+0.10(10)=7.\]

A transformer uses a mechanism called attention that includes this same weighted-combination idea. Real models perform the calculation on vectors rather than single numbers, but we can understand one coordinate at a time.

Step 3 · Worked example

A sentence can create different weights

Consider “The dog chased the ball because it was moving.” In a simplified example, processing “it” might assign different weights to earlier information:

Earlier tokenOne numerical featureWeight
dog20.10
chased50.20
ball80.60
moving100.10

The result is 7. The number 8 does not literally mean “ball-ness.” Real models use many numerical coordinates. We are isolating the familiar weighted-average structure.

A few new words

Vocabulary after the mathematics

These terms name ideas you have already seen above.

weightA number telling how strongly a value contributes.
weighted averageA sum of values multiplied by weights.
attentionA transformer mechanism that forms context-dependent weighted combinations.
vectorAn ordered list of numbers; real LLM calculations use many coordinates.

What to carry forward

The AI idea of this module

The Module 3 bridge is

\[\text{ordinary mean}\longrightarrow\text{weighted mean}\longrightarrow\text{attention-like weighted combinations}.\]

You do not need matrix algebra yet to understand the central idea that information can be combined with different weights.
