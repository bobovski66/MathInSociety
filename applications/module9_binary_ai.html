How one word changes the next choice

A language model chooses between possible next pieces of text. Each choice changes what might come next.

Four possible continuations

Imagine a small model completing the sentence “The delivery is ...” The first word is either early or late; the second is today or tomorrow. These are invented teaching probabilities, not measurements from a real AI model.

Multiply along a path. If the first branch has probability 60% and the next branch has probability 50%, the chance of the complete path is 0.60 × 0.50 = 0.30, or 30%.
