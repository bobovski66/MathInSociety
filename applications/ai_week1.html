AI Mathematics 1 — Text Becomes Numbers

Tokens, token IDs, finite vocabularies, and recursive generation: the first step from language to arithmetic.

Why this belongs in Math in Society

Before a language model can calculate with text, the text has to become numbers.

A computer does not begin with a sentence as a human-readable object. A language model first breaks text into tokens: small pieces such as words, parts of words, punctuation, or spaces attached to words. Each token has an integer token ID.

For a toy vocabulary we might assign the → 3, cat → 9, and mat → 15. The ID is only an address in a vocabulary. Token 9 is not “nine units of cat.” It is simply the ninth stored symbol in our toy system.

What is simplified here? Real tokenizers may split an unfamiliar word into several pieces, and real vocabularies contain many thousands of tokens. A real LLM also uses the entire available context, not merely the previous token.

If a vocabulary has (V) possible tokens, then there are (V^2) possible ordered two-token strings and (V^3) possible ordered three-token strings. Generation is recursive: after a new token is appended, the enlarged text becomes the context for the next prediction.
