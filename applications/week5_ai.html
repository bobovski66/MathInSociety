Module 5: AI Application — Surprise, Bits, and Language

Why predicting ordinary text is deeply connected to information and compression.

Why this page exists

Mathematics gives us a way into AI

A language model is rewarded when it assigns high probability to tokens that actually occur. Information theory gives us a numerical way to measure how surprising an observed token was under the model.

Important: the examples on this page are intentionally tiny models. Real LLMs use huge vectors, many layers, and billions of learned numerical parameters. We simplify the scale while keeping the mathematical structure recognizable.

Connection to this module

The mathematics you already know

Module 5 already defines information in bits. For an event with probability \(p\), its information content is \[ I=-\log_2(p). \] A likely event carries fewer bits of surprise; an unlikely event carries more.

AI vocabulary

Four ideas to carry with you

surprisalThe information content \(-\log_2 p\) of an observed outcome.
bitA unit of information.
cross-entropyAn average measure of how surprising the actual data are under a model.
compression connectionBetter predictions allow more efficient encoding because predictable events need fewer bits.
Worked example

Follow the numbers

If a model gives the correct next token probability \(1/2\), then \[ I=-\log_2(1/2)=1\text{ bit}. \] If it gives the correct token probability \(1/32\), then \[ I=-\log_2(1/32)=5\text{ bits}. \] The second event was far more surprising to the model.
Investigation

Try the mathematics yourself

1. How many bits of information correspond to probability 1/8?

2. How many bits correspond to probability 1/64?

3. A model assigns the actually observed tokens 1, 3, 2, and 2 bits of surprisal. What is the average surprisal?

4. Which model prediction is better for an outcome that actually occurs?

What to remember

AI idea of the week

Training a language model can be viewed as learning to reduce average surprise. This is one reason language modeling and data compression are mathematically close relatives.

You do not need to know every engineering detail of an LLM to reason mathematically about what it is doing. We will keep adding one mathematical layer at a time.
