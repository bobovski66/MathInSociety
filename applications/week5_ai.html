Module 5: AI Application — Learning as a Feedback Loop

A neural network becomes an adaptive system when the result of one attempt is used to change the next attempt.

A question for this module
What turns a prediction machine into a learning system?

A trained network can take an input and produce an output. Training adds something else: the output is compared with a target, an error is measured, and adjustable weights are changed before the next attempt.

The cybernetic picture

Close the loop around prediction

make a prediction
measure error
change weights
predict again

The prediction alone is a one-way pass. Learning appears when information about the result returns to change the system.

A tiny model

One adjustable weight

Let an adjustable weight be \(w\). For this toy example, the prediction is twice the weight:

\[\widehat y=2w.\]

The target is \(6\). After each attempt, compute

\[e=6-\widehat y,\qquad w_{\text{new}}=w+0.25e.\]

Start with \(w=1\). The first prediction is \(2\), the error is \(4\), and the next weight is \(1+0.25(4)=2\). The next prediction is \(4\), which is closer to the target.

Keep the scale in perspective. A real neural network contains many adjustable weights. This one-number example isolates the feedback structure so we can see it.
Backpropagation

How does the error reach all those weights?

In a large neural network, one final error must be connected to many adjustable weights spread across many layers. Backpropagation works backward through the network to determine how the error is connected to those weights. A training rule then changes them.

At this level, the central idea is:

\[\boxed{\text{attempt}\to\text{error}\to\text{change}\to\text{new attempt}}.\]

Later mathematics can make the size and direction of each weight change precise. For now, the feedback loop is the important structure.

The larger idea

Machine learning is one member of a much larger family. A thermostat changes heat after measuring temperature. A driver changes pressure on the accelerator after measuring speed. A learning system changes adjustable weights after measuring error. The details differ, but all use information from what happened to influence what happens next.
