Module 5: AI Application — Surprise, Bits, and Language

Information theory lets us measure how surprised a model is by the text that actually occurs.

A question for this module
How can we put a number on a prediction being 'surprising'?

A probability tells us how expected an event is. Information theory turns that idea around: rare events carry more surprise, and therefore more information. That gives us a remarkably direct way to score language predictions.

Start with familiar mathematics

The Module 5 idea

In Module 5, the information content of an event with probability \(p\) is \[ I=-\log_2(p). \] For powers of 2, the calculation is especially transparent: \[ \frac18=2^{-3}\quad\Rightarrow\quad I=3\text{ bits}, \] while \[ \frac1{64}=2^{-6}\quad\Rightarrow\quad I=6\text{ bits}. \] The rarer event carries more bits of information.
Now put that mathematics to work

The AI connection

Now suppose the actual next token in a piece of text is “river.” Before seeing it, a language model assigns “river” some probability. If the model assigns “river” a large probability, the observed token is not very surprising. If it assigns “river” a tiny probability, the observed token is very surprising. This is one way language-model training can be described mathematically: reward probability assignments that make the actual text less surprising.
Keep the scale in perspective. These numbers are deliberately small so the calculation is visible. A real LLM uses a much larger vocabulary, high-dimensional vectors, and many repeated layers. We are isolating one genuine mathematical structure at a time.
Follow one example

Work through the calculation

Imagine two models predicting the same observed token. Model A assigns \[ P(\text{river})=\frac12. \] Then \[ I_A=-\log_2(1/2)=1\text{ bit}. \] Model B assigns \[ P(\text{river})=\frac1{32}. \] Then \[ I_B=-\log_2(1/32)=5\text{ bits}. \] The token “river” was much less surprising to Model A. Over many tokens, we can average these surprise values. In machine learning, closely related averages appear as cross-entropy loss.

Where this leaves us
This gives us a powerful connection: \[ \text{better prediction}\longleftrightarrow\text{less surprise}\longleftrightarrow\text{fewer bits}. \] That is why prediction, information, and compression keep appearing together in the mathematics of language models.
