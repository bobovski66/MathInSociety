Application — Community Alert Network

Use paths and direct connections to plan how an urgent community notice can reach residents.

Scenario

A community group can send an alert along these links: Coordinator–Library, Coordinator–Clinic, Library–School, Clinic–School, School–Shelter, Shelter–North Block.

Assume each link carries a message to its neighbor in one round.

Investigate

  1. Draw the six nodes and six links. Find each node’s degree.
  2. If the coordinator sends first, which locations get the alert after one round? After two rounds?
  3. Which single link is a bottleneck for reaching North Block? Explain.
  4. Suggest one additional link that would make the network more resilient. How does it change possible paths?

A high-degree location can spread a message quickly, but a low-degree bridge may be critical to keeping distant groups connected.
