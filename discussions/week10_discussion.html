The problem

Two teams observe the same population

An observation station uses the simplified logistic model

\(x_{n+1}=3.9x_n(1-x_n).\)

Two teams’ estimates of the initial state differ by 0.0001. Choose one pair below and compare how those two estimates develop under exactly the same rule.

PairStarting state AStarting state B
A0.20000.2001
B0.25000.2501
C0.35000.3501

The starting values are at generation 0. Keep full stored precision during the calculation; display at least six decimal places in your table.

Example of a table row

For pair A at generation 0, record 0.200000, 0.200100, and an absolute gap of 0.000100. To obtain generation 1, apply \(3.9x(1-x)\) separately to each starting value.

Initial post

Show the calculation and its meaning

  1. Name your pair and show one complete update calculation for each starting state.
  2. Include a table of generation, state A, state B, and absolute gap for generations 0 through 10. Continue through the first generation where the gap exceeds 0.05, or through generation 15 if it has not crossed by then.
  3. Report the first crossing you found. If no crossing occurs by generation 15, say so; do not treat “not observed yet” as “never.”
  4. Explain how an initially small measurement difference affects later forecasts. State why the rule is still deterministic.
  5. Explain what would happen if both starting values were rounded to only three decimal places before iteration.

A clear table, labeled graph, or image of organized handwritten work is appropriate. Use the numerical results to support your explanation.

Replies

Compare another observer’s result

Follow the reply instructions in Canvas. If possible, choose a classmate who used a different initial pair. Compare threshold-crossing times and check at least one calculation. Explain why a different crossing time is compatible with both pairs following the same formula.

A useful reply identifies a mathematical detail: a calculation, a rounding choice, a threshold, or the meaning of a forecast. The page provides the problem and checking tools; post your response on the class discussion board.

What the experiment supports

A pair of forecasts can illustrate sensitivity to initial measurements. It does not give guaranteed bounds for every possible state, prove that an actual population is chaotic, or show that all future questions are unanswerable.
