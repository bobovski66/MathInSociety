Week 9 / Discussion

Make a connection. Defend the choice.

Choose one new link in a mutual-aid network, test what it changes, and help a classmate strengthen their reasoning.

A checkable claimA route or failure testA substantive reply

The question

Which local change would you make—and for what goal?

A regional mutual-aid network has seven groups, A through G. Each link means the two groups have an established two-way contact for coordinating resources. The links are AB, AC, BC, BD, CD, DE, EF, EG, FG.

Groups A–D form one region; E–G form another. D–E is the only link between them. The picture records who can contact whom, with all links counted equally. It does not measure trust, travel time, capacity, or the reliability of a particular contact.

Build a claim another student can check

Choose one goal: faster communication from A, continued reach after D–E fails, or protection against a particular group going offline. Add exactly one new link, and explain how it serves that goal. You may choose a different link from the one studied in the application.

  1. State the model and goal. Name the link and say what “better” means.
  2. Show evidence. Include a numerical measurement or an explicit route and failure test. Use at least two of: degree, distance, a first-arrival round, components, a bridge, an alternate path.
  3. Test the limit. Name an outage or other goal your link does not solve. A link can improve one thing while leaving another unchanged.
  4. Question the model. Identify one missing real-world feature and say what information you would need to investigate it.

A focused paragraph or two—roughly 200–300 words—is enough if the mathematics is clear. Include a drawing if useful, or give the edge list and routes in text.

A worked miniature: what counts as evidence?

Consider a different network, the four-node path P–Q–R–S. A weak claim is “I would add P–S because more connections are better.” A checkable claim is:

Claim → calculation → implication → limit

“I would add P–S to preserve contact if Q–R fails. After that failure, P–S–R still joins the two sides, so the remaining network is connected. With all links working, the P-to-S distance also drops from 3 to 1. The model assumes the new link works independently; if one outage disables several links together, I need a different failure test.”

The route is evidence because every consecutive pair is an available edge in the changed network. The limitation names a specific assumption rather than saying only “the real world is complicated.” Use that structure for your own choice in the seven-node network.

Think beyond a single score

One student says, “D is crucial because every original route between regions passes through it.” Another says, “B and C are just as crucial because their degrees also equal 3.” What does each claim actually establish?

Equal degree establishes equal numbers of direct neighbors. It does not establish equal positions on routes. If the goal concerns travel between regions, trace those routes. If the goal concerns immediate contacts, degree is relevant. You can acknowledge both observations while deciding which one addresses the stated goal.

Optional stretch: link failure versus group failure

Adding D–F creates a second cross-region link, but both routes still use D. If your goal is surviving loss of D itself, test a link with a different left-side endpoint. Remove D and all its incident edges, then trace what remains. Do not treat losing one link and losing a whole group as the same event.

Reply by testing a classmate’s idea

Choose a classmate’s proposed link and test it against a different objective or failure. Name their link, show a specific route or count, and explain the consequence. For example: after D–E fails, can A still reach G? If D goes offline, what happens to the remaining components? Does the new link shorten A’s farthest arrival time?

A useful reply can extend an argument or reveal a limitation. “I agree” alone gives your classmate no mathematical feedback. If you find an error, point to the particular missing link, mistaken count, or changed assumption so the reasoning can be repaired.

Before you post

  • My added edge is genuinely new.
  • I named the objective and used the appropriate network.
  • Every edge in my route exists and is available in the stated scenario.
  • I counted path edges, distinguished new arrivals from totals, and named the failure I tested.
  • I connected a model limitation to information we could seek.

The aim is a defensible intervention, not a universally best link. The mathematics helps make consequences visible so a community can discuss its priorities.
