Module 5 Discussion — When Measurement Changes Behavior

Use a simple school feedback loop to think about what measurement can accomplish—and what it can miss.

How this discussion works

Solve, present, then respond

Work the problem below before reading classmates' solutions. Show the short calculations, then explain what the feedback loop is doing in ordinary language.

Context

A tutoring program responds to weekly checks

A tutoring program wants a class mastery score near 80. After each weekly check, extra practice is added according to

\[\text{next score}=\text{current score}+0.50(80-\text{current score}).\]

Initial post

What to include

  1. Compute the first three observed values beginning with 56.
  2. Identify the target, measurement, error signal, and action in this system.
  3. Explain why the rule is corrective feedback rather than amplifying feedback.
  4. Explain one possible problem caused by a noisy or misleading measurement.
  5. Give one other example from society in which measuring something changes what people or institutions do next.
