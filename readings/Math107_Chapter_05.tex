\Needspace{6\baselineskip}\section{A subscript tells you when, not how much to multiply}

A \emph{sequence} is an ordered list. A \emph{recursive rule} tells us how to use earlier values to find a new one. If \(a_0=10\) and \(a_{n+1}=a_n-2\), the list begins \(10,8,6,4,\ldots\). Starting at step 0, three updates take us to \(a_3=4\). There are four listed values but only three changes.


For our greenhouse, let \(x_n\) mean temperature in degrees Fahrenheit at step \(n\). We will treat each step as one hour. Thus \(x_0=64\) is the starting temperature, \(x_1\) is the temperature after one update, and \(x_2\) is the temperature after two updates. The subscript is a label for time. It is neither an exponent nor a multiplication.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/subscript-timeline.pdf}
\captionof*{figure}{Read the index first: previous, current, next. The history value x$_{-}$$_1$ is a temperature before the start, not a negative temperature.}
\end{minipage}\par\medskip

\begin{tcolorbox}[title={Translate the notation before calculating},breakable]

If we are at step \(n=2\), then \(x_{n-1}=x_1\) means the previous temperature, \(x_n=x_2\) means the current temperature, and \(x_{n+1}=x_3\) is the next one we want to find.


\end{tcolorbox}

\end{tcolorbox}


\Needspace{6\baselineskip}\section{A reading becomes feedback when it changes the next action}

A thermometer on a wall can display the temperature without controlling anything. A thermostat uses the reading to decide whether to change heating or cooling. That action changes the room, which changes the next reading. Information returns to influence the process that produced it. This returning influence is \emph{feedback}.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/feedback-loop.pdf}
\captionof*{figure}{The arrows form a loop: the action changes the condition that will supply the next observation.}
\end{minipage}\par\medskip

The \emph{state} and the \emph{measurement} need not agree. The state is the temperature actually present now; a measurement is a report about temperature. It might describe an earlier hour or contain an error. Our first model makes them agree so we can see one idea at a time.

\Needspace{6\baselineskip}\section{Start here, measure a difference, make a correction}

Our invented greenhouse starts at 64°F and has target \(r=70\)°F. Its controller corrects half of the reported difference each hour. We assume the equipment can produce that exact net temperature change, in either direction. There is no sunlight, heat loss, equipment limit, or random measurement error in this model. These assumptions make the timing of feedback visible.


The \emph{control error} is target minus the report used for the decision. ``Error'' here means a signed difference, not an arithmetic mistake. A 64°F report gives \(70-64=+6\): the report is below target. A 73°F report gives \(70-73=-3\): the report is above target.

\[\text{correction}=k(\text{target}-\text{report}),\qquad \text{next}=\text{current}+\text{correction}.\]
The \emph{response strength} \(k\) says how much of that difference we use. With \(k=0.5\), we use one-half of the reported difference. With a current report, the rule becomes

\[x_{n+1}=x_n+0.5(70-x_n).\]
\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/error-correction.pdf}
\captionof*{figure}{Correct half of the remaining difference at each step. The original 6°F gap is not reused forever.}
\end{minipage}\par\medskip

\begin{tcolorbox}[title={Write the first two updates in full},breakable]

First: \(x_1=64+0.5(70-64)=64+3=67\).


Second: \(x_2=67+0.5(70-67)=67+1.5=68.5\).


The second correction is smaller because it uses the new temperature, 67. Continue by putting 68.5 into the same rule.


\end{tcolorbox}

\Needspace{6\baselineskip}\section{The new state still starts from now}

Keep the same target, starting temperature, and response strength. Change only the thermometer's delivery time. The report available at step \(n\) now describes step \(n-1\). The correction uses the older report, but it is added to the \emph{current} temperature:

\[x_{n+1}=x_n+0.5(70-x_{n-1}).\]
The two subscripts do different jobs. At step 2, \(x_2\) is where we start the next change, while \(x_1\) supplies the report. We need an earlier history value to begin: assume \(x_{-1}=x_0=64\). This says the greenhouse was also 64°F one hour before our start.


\begin{tcolorbox}[title={Watch the two numbers travel through the rule},breakable]

At step 0: current 64, old report 64, correction +3, so \(x_1=67\).


At step 1: current 67, old report still 64, correction +3, so \(x_2=70\).


At step 2: current 70, old report 67, correction +1.5, so \(x_3=71.5\).


The system has reached its target at step 2. The available report has not caught up, so the next correction carries it beyond 70.


\end{tcolorbox}

\Needspace{6\baselineskip}\section{The graph shows when the direction changes}

Put step number on the horizontal axis and temperature on the vertical axis. Each dot is a calculated state; connecting segments help your eye follow the sequence. They do not specify exactly how temperature changes within an hour. The dashed horizontal line marks 70°F.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/immediate-delayed.pdf}
\captionof*{figure}{Both paths start at 64°F, use target 70°F and response strength 0.5. Report age is the only difference. The temperature axis begins at 63°F to make the small differences visible.}
\end{minipage}\par\medskip

\emph{Overshoot} means passing the target. \emph{Oscillation} means repeated back-and-forth variation. A \emph{damped oscillation} has a shrinking envelope of departures from the target: compare successive peaks or troughs. Not every single step has to move closer, and two consecutive states can be equal.


In our delayed sequence, steps 3 and 4 are both 71.5, above the target. Steps 7 and 8 are both 69.625, below it. The sequence continues with smaller swings. The controller is responding to past shortages and excesses after the actual condition has changed.

Use the table to explain a particular overshoot. A finite plot alone does not prove what every later value will do. In this fixed mathematical example the oscillation does decay, but a similar-looking short beginning is not a universal guarantee.


\end{tcolorbox}

\Needspace{6\baselineskip}\section{Current information can still produce an overreaction}

A delay can cause a swing, but delay is not the only cause. With current reports and \(k=1.5\), the first correction is \(1.5(70-64)=9\). Starting at 64, the temperature jumps to 73. The next error is $-$3, the correction is $-$4.5, and the temperature becomes 68.5. The sequence begins \(64,73,68.5,70.75,\ldots\).


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=4.1in,keepaspectratio]{../assets/week5/strength-comparison.pdf}
\captionof*{figure}{These four cases use current measurements. Compare panels on the same temperature scale; changing response strength alone can change the behavior.}
\end{minipage}\par\medskip

There is a short way to understand the immediate rule. If the old gap is \(r-x_n\), the correction removes \(k\) times that gap. The gap left afterward is \((1-k)(r-x_n)\). For \(k=0.5\), one-half of the gap remains on the same side. For \(k=1.5\), the remaining gap is $-$0.5 times the old one: half the size, on the other side.


\par\medskip{\small\renewcommand{\arraystretch}{1.35}\begin{tabularx}{\linewidth}{@{}YY@{}}\toprule
Strength k & Immediate rule, starting away from the target\\
\midrule
0 & No correction; the state stays where it starts\\
0 \textless{} k \textless{} 1 & Approaches without crossing\\
1 & Reaches the target in one update\\
1 \textless{} k \textless{} 2 & Crosses repeatedly; departures shrink\\
2 & Alternates between two equal departures\\
k \textgreater{} 2 & Alternating departures grow\\
\bottomrule\end{tabularx}}\par\medskip

This table is about this particular rule with \emph{current} reports. Do not apply its thresholds unchanged to delayed controllers. If the state starts exactly at the target, zero error keeps it there under any of these strengths in the ideal model.

\Needspace{6\baselineskip}\section{A late reading and a noisy reading create different problems}

A delayed report can be perfectly accurate about an earlier hour. A noisy report fluctuates around what it measures. A biased sensor consistently reads too high or too low. A rounded report loses some precision. More than one of these can occur at once.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/noise-vs-delay.pdf}
\captionof*{figure}{Ask two separate questions: what time does this report describe, and how well does it describe that time?}
\end{minipage}\par\medskip

\begin{tcolorbox}[title={A z-score judges unusualness under a stated model},breakable]

Suppose a steady 68°F environment produces approximately normal sensor readings with mean 68 and standard deviation 2°F. A reading of 72 has \(z=(72-68)/2=2\). It is two standard deviations above the mean. It is unusual under that model, but it does not by itself prove a temperature change or a broken sensor. Compare the report with other evidence.


\end{tcolorbox}

For independent, unbiased readings of the same steady condition, averaging \(m\) readings reduces the standard deviation of the average to \(\sigma/\sqrt{m}\). With individual standard deviation 2°F, averages of 1, 4, and 16 readings have standard deviations 2, 1, and 0.5°F. This is variability across repeated averages, not a promise that any particular average is exactly right.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/averaging.pdf}
\captionof*{figure}{If one reading arrives each minute, a batch of m readings spans m $-$ 1 minutes. Precision improves under the steady, independent, unbiased model; the information also covers a longer past interval.}
\end{minipage}\par\medskip

Averaging cannot remove a shared bias, and correlated readings may provide less improvement. If the temperature is changing while we gather data, an average of past readings is not simply a precise measurement of the present. This creates a practical question: how much information can we gather before the action becomes late?


\begin{tcolorbox}[title={Pause and try 7},breakable]
A sensor always reads 2°F too high. Will averaging 16 of its readings remove that 2°F bias?
\end{tcolorbox}

Reference for the sampling-mean framework: \href{https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm}{NIST Engineering Statistics Handbook}. The calculation here assumes independent readings of the same steady state.

\Needspace{6\baselineskip}\section{Correct, amplify, or adapt}

\emph{Corrective}, or negative, feedback opposes a measured departure. \emph{Amplifying}, or positive, feedback reinforces a change. These words describe direction, not whether the result is good or bad. An \emph{adaptive} system changes its adjustable rule or parameters using information from earlier results. Adaptation is another feature of a system, rather than a third mutually exclusive sign of feedback.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/feedback-types.pdf}
\captionof*{figure}{First ask what the loop does to a departure; then ask whether it can change how it responds.}

\Needspace{5\baselineskip}\subsection*{Amplification uses the updated amount}

Suppose a hypothetical exposure index begins at 100 and grows by 20\% per round. The rule \(v_{n+1}=1.2v_n\) gives \(100,120,144,172.8,\ldots\). The second increase is 24, not 20, because the base is now 120. These are index values, so decimals are meaningful. A real count of people is whole, and an actual spreading process has a finite audience and other limits.


\Needspace{5\baselineskip}\subsection*{A learning rule generates a sequence of weights}

Let a toy predictor use \(\widehat y=2w\), where \(w\) is an adjustable number called a weight and \(\widehat y\) means prediction. The target output is 6. Choose the training rule \(w_{n+1}=w_n+0.25(6-2w_n)\), starting at \(w_0=1\).

Attempt n & Weight w$_n$ & Prediction 2w$_n$ & Error 6 $-$ prediction & Next weight\\
\midrule
0 & 1 & 2 & 4 & 2\\
1 & 2 & 4 & 2 & 2.5\\
2 & 2.5 & 5 & 1 & 2.75\\
3 & 2.75 & 5.5 & 0.5 & 2.875\\

The successful weight is 3 because \(2(3)=6\). Notice the units of the two goals: a weight of 3 gives a prediction of 6. They are not interchangeable. This one-example model shows how returned information can alter future predictions; it cannot establish success on other examples.

\Needspace{6\baselineskip}\section{A message can be represented, checked, and interpreted}

The greenhouse thermometer sends a signal to its controller. A digital signal can represent a measurement as a string of bits, each 0 or 1. With 3 bits there are \(2^3=8\) possible patterns. The code must specify what each pattern means; the symbols alone do not supply the interpretation.


Extra structure can help detect damaged messages. With \emph{even parity}, append a bit so the total number of 1s is even. The data 1011 has three 1s, so append 1 to get 10111. One flipped bit makes the total odd and signals an error. Two flipped bits can leave the count even. This check detects any single-bit change but does not identify or repair it.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/bit-parity.pdf}
\captionof*{figure}{More information in the message can help check transmission. Passing this check does not establish that the original sensor reading was timely or accurate.}
\end{minipage}\par\medskip

Information theory also measures \emph{surprise relative to a probability model}. An event assigned probability \(p\) has surprisal \(I=-\log_2 p\) bits. You can use powers of two without knowing logarithm techniques: probabilities 1/2, 1/4, and 1/8 correspond to 1, 2, and 3 bits. A less probable event carries more surprise under that model. ``More bits'' does not by itself mean more truth, social value, or importance.


\emph{Entropy} is average surprise across possible outcomes. A fair coin has two equally likely outcomes and entropy 1 bit per toss. A coin that always lands heads has entropy 0, since its outcome is certain. The timeline's coin experiment makes that distinction visible; the optional AI Mathematics page scores predictions for observed tokens.

\Needspace{6\baselineskip}\section{Who sets the target, and who observes the observer?}

A classroom may use assessment results to change instruction. Students respond to the new instruction and to the assessment itself. Their responses change what the instructor observes next. The observer's decisions become part of the situation being observed.


\par\medskip\noindent\begin{minipage}{\linewidth}
\centering\includegraphics[width=\linewidth,height=2.8in,keepaspectratio]{../assets/week5/observer-loop.pdf}
\captionof*{figure}{In human systems, a measured score is a limited indicator of a larger goal. The choice of target and measurement deserves discussion.}
\end{minipage}\par\medskip

Norbert Wiener's 1948 \emph{Cybernetics} connected communication and control in machines and living systems. Claude Shannon's 1948 communication theory studied messages, uncertainty, noise, and reliable transmission. These are connected subjects with different central questions.


Anthropologist Margaret Mead helped bring questions about culture and social organization into the interdisciplinary Macy Conferences. In a 1967 address published in 1968 as \emph{Cybernetics of Cybernetics}, she asked whether the American Society for Cybernetics could apply cybernetic ideas to its own organization. The people studying feedback could also examine their own feedback loops.


The illustrated history preserves a broad cast: human computers, programmers, engineers, mathematicians, psychologists, and organizers. Follow the contributions of Mead, Janet Freed, Rózsa Péter, F. Jessie MacWilliams, Vera Pless, and other women alongside Wiener and Shannon. You are not expected to memorize all 63 entries. Use the guided routes to explain how one historical problem connects to this week's mathematics.


\begin{tcolorbox}[title={A model can describe the consequences of a chosen goal},breakable,colback=warm,colbacktitle=warm,coltitle=gold,colframe=gold!35]

It cannot decide by itself whether that goal is fair, whether the measurement represents everything that matters, or whose experience is missing. In a school, a higher test score may be one useful observation; it is not a complete definition of learning.


\end{tcolorbox}

\subsection*{A text predictor assigns probabilities to the next token}
A token is a model's unit of text; it may be a word, a word fragment, or punctuation. Suppose a predictor gives the token that actually occurs probability $p$. Its surprisal is $I=-\log_2 p$ bits. For $p=1/2^k$, the score is $k$ bits.

\begin{center}\includegraphics[width=\linewidth,height=2.7in,keepaspectratio]{../assets/week5/information-bits.pdf}\end{center}
For four observed tokens given probabilities $1/2,1/4,1/8,1/4$, the scores are 1, 2, 3, 2 bits. Total surprise is 8 bits; average surprise is 2 bits per token. This empirical mean negative log probability is commonly called cross-entropy loss for the observed sequence. Its perplexity is $2^2=4$, an effective uncertainty scale. It is not necessarily the number of choices offered at every position.

Under an idealized coding model, 100 tokens averaging 2 bits per token correspond to about 200 bits, apart from coding overhead. Actual coding methods approach this scale over sequences; a fractional-bit score need not be a literal fractional stored bit for an isolated token.

The score can supply information for a training update, but it is not a complete learning algorithm. Lower surprise on one observed token does not establish performance across a task, truthfulness, or usefulness. Entropy averages over possible source outcomes; empirical cross-entropy averages a model's surprise over observed outcomes. Natural-log software conventions give nats rather than bits without changing which probability has lower surprise.

\begin{tcolorbox}[title={An endpoint matters}]
If $p=1$, surprisal is 0. If a model assigns $p=0$ to an event that occurs, its surprise has no finite value. The finite surprise calculator requires $0<p\leq1$. In entropy calculations, the contribution $p\log p$ has limiting value 0 at $p=0$.
\end{tcolorbox}

\subsection*{Chapter review: solutions}
\begin{enumerate}
\item The list is $7,11,15,19,23$, obtained by four updates. At $n=3$, $a_{n-1}=a_2=15$ is the preceding value. An index labels the term's place; it is not a power.
\item A float or level sensor measures water depth. A controller compares its report with a chosen depth and opens or closes a valve or adjusts a pump. The changed level produces the next reading. A fixed schedule does not use a level measurement to choose its next action. Other sensible designs are possible if the return path is explicit.
\item First row: current/report 84, error 16, correction 4, next 88 cm. Second: current/report 88, error 12, correction 3, next 91 cm. Each update removes one-quarter of the remaining gap and leaves three-quarters. The second correction is not another 4 cm.
\item States are 67, 68.5, 69.25, 69.625. The corrections are 3, 1.5, 0.75, 0.375. Adding 3 repeatedly ignores the changing reported error and eventually passes the target; it is not the stated half-gap controller.
\item States are 67, 70, 71.5, 71.5, 70.75, 70, 69.625. To produce $x_3$, current $x_2=70$ uses report $x_1=67$, error 3 and correction 1.5. To produce $x_4$, current $x_3=71.5$ uses report $x_2=70$, error and correction 0. The first correction acts on an earlier shortage that no longer describes the present.
\item The delayed order is $0.5(100-80)=10$ units. The current report would give $0.5(100-60)=20$. The model omits effects such as sales during delivery, pending orders, delivery time, whole-unit and minimum-order constraints, and finite storage. Specify which effect your explanation uses.
\item For $k=0.5$: $0,5,7.5,8.75$; half the gap remains on the same side. For 1.5: $0,15,7.5,11.25$; gaps switch side and halve. For 2: $0,20,0,20$; equal departures persist. For 2.5: $0,25,-12.5,43.75$; absolute gaps grow by factor 1.5. Starting exactly at 10 gives zero error and an unchanged state under all these ideal rules. The table's thresholds do not transfer unchanged to delayed rules.
\item The displayed peaks decrease in those eight steps, assuming the graph was read accurately. That alone does not prove all later peaks shrink or that the sequence converges. Overshoot is passing a reference; oscillation is repeated back-and-forth variation. A damped oscillation has a shrinking envelope of departures; convergence means later values approach one limit. A persistent equal-amplitude oscillation does not converge.
\newpage
\item $z=(72-68)/2=2$; $z=(65-68)/2=-1.5$. They describe distance from the assumed mean in standard-deviation units. Neither alone proves a change or a failure. A reading can be unusual under a steady-state noise model without being impossible. Further observations and sensor checks can help distinguish explanations.
\item Standard deviations of the averages are 2, 1, and 0.5 degrees. Oldest-reading ages are 0, 3, and 15 minutes. The shared +2-degree bias remains after averaging. Independence, unbiasedness, and a steady underlying state matter; correlated readings or a changing state require a different interpretation.
\item Thermostat: corrective, opposing a reported departure. Microphone squeal: amplifying, when speaker sound re-enters the microphone and reinforces the signal. The exposure index is amplifying, with values 100, 120, 144, 172.8. Decimals are appropriate for an index, not literal fractional people. An adaptive system changes its response rule or parameters using results; it can also use corrective feedback. Real amplification faces physical or social limits.
\item New weights are 2, 2.5, 2.75, 2.875, with predictions 4, 5, 5.5, 5.75. The weight target is 3, while the output target is 6. Success on this one fixed example does not test generalization, robustness, fairness, or performance on new data. Backpropagation and an optimization rule serve different roles in a larger network.
\newpage
\item With step size 0.75, first error 4 gives weight $1+0.75(4)=4$, prediction 8. The next error is $6-8=-2$, giving weight 2.5, prediction 5. The strong current response crosses the weight target 3. With delayed errors and step size 0.25, weights are 2, 3, 3.5. The third update uses the older weight 2 and its prediction 4, so a positive correction 0.5 is added when the current weight is already 3. The new prediction is 7, beyond output target 6.
\item Append 1 to make 10111, with four 1s. A single third-bit flip gives 10011 with three 1s, so the check fails. Flipping the first two bits gives 01111 with four 1s, so this two-bit change passes. Parity does not identify or repair the damage and does not check sensor truth or report age. Since $1/32=2^{-5}$, surprisal is 5 bits under that probability model.
\item Token scores are 1, 2, 3, 2 bits; total 8 and mean 2 bits per token. Perplexity is $2^2=4$. A has 1-bit surprise and B 3-bit surprise on the specified observed token, so A has lower loss there. This single comparison cannot rank their full-task performance or usefulness. The idealized coding scale is $100(2)=200$ bits, apart from overhead.
\item Shannon formalized message uncertainty, channels, noise, and communication limits. Wiener connected communication to action and regulation in feedback systems. Mead asked how a society studying cybernetics could apply those ideas to its own organization. In a classroom, quiz results may guide changed instruction, but focusing only on scores might encourage narrow preparation or miss deeper understanding. Student explanations, reflection, discussion, and feedback on assessment design can add evidence. A strong response names its specific goal, observation, action, return path, and historical source.
\end{enumerate}
