Computing with two choices

A community center wants to send callers to the right service. Can it do that by asking them to choose between 0 and 1?

We'll use two symbols first to represent numbers, then to follow addresses in a tree, and finally to make choices in a small program. All the calculations use counting, addition, and multiplication.

1. Counting with zeros and ones

Our usual number system uses ten digits. Binary uses only 0 and 1. In binary, the places are worth 1, 2, 4, 8, 16, 32, and so on. Each place is twice the value of the one to its right.

Place values168421
Binary digits01101
Count the ones. The code 01101 is worth 0 + 8 + 4 + 0 + 1 = 13. Usually we omit leading zeros, so we write 1101 for the same number.

To write 11 in binary, use 8 + 2 + 1. Those places get the digit 1 and the 4's place gets 0. The answer is 1011.

Try it. What is 10110 in decimal? Write 14 in binary. Check your work with the explorer.

2. A sequence of choices becomes an address

Give the same digits a different job. At every junction in a branching diagram, 0 means go left and 1 means go right. A binary address describes a route. For example, 101 means right, left, right.

After two choices there are four addresses: 00, 01, 10, 11.

Follow 01. Go left on the first choice and right on the second. You arrive at 01. A third choice extends the address to 010 or 011. We call 01 a prefix of those longer addresses.

One choice produces 2 addresses, two produce 4, three produce 8, and four produce 16. After n choices, there are 2n possible addresses. Each extra choice doubles the number.

Try it. List all eight three-digit addresses. How many four-digit addresses start with 10?

3. A decision tree becomes a program

The community center answers calls about food pantry hours, bus schedules, regular rides, and urgent rides. A caller chooses 0 or 1 at each junction and stops when the menu reaches a service.

CodeServiceQuestions
0Food pantry hours1
10Bus times2
110Regular ride help3
111Urgent ride help3

This is a simple decision program: the instructions say which branch to follow, and each service is an instruction to stop. A caller entering 110 answers three questions and reaches regular ride help.

None of the stopping codes begins another stopping code. If 1 also meant stop, the caller could never enter 10, 110, or 111. This property is called prefix-free.

Try it. Follow code 111. Then design a menu for four services that uses exactly two questions per caller. Which four two-digit codes would you use?

4. Which menu asks fewer questions?

The center receives 16 calls: 8 about food pantry hours, 4 about bus times, 2 about regular rides, and 2 about urgent rides. We can count the total number of questions.

Try it. If the call counts change to 6, 5, 3, and 2, what is the new total for each menu? Which takes less work?

5. What if the tree keeps growing?

Our phone menu stops. But we could imagine a binary tree with no final level. Every address can be extended by another 0 or 1. The finite address 101 leads to 1010 and 1011, and each of those can continue. An infinite path would be a never-ending sequence of choices. A finite prefix tells us what has happened so far, not the next digit.

One short rule changes the possible routes. Suppose the code may never contain 11. The allowed two-digit addresses are 00, 01, 10 (three instead of four). The allowed three-digit addresses are 000, 001, 010, 100, 101 (five instead of eight).

A simple rule can constrain the choices at every level. The explorer lets you count the allowed strings with as many as six digits.

Try it. Write two allowed four-digit addresses and one forbidden address. If an allowed string ends in 1, what must the next digit be?

The phone menu uses a finite subtree of this never-ending tree: it keeps only the junctions needed to reach four services, with a stopping instruction at each service. This simple program always finishes after a limited number of questions. Other programs can repeat instructions in loops, so even a short set of instructions may run for a long time.

6. Make a decision with the mathematics

Binary digits can represent a number, an address, or an instruction. Their meaning depends on the rule. A useful decision tree makes the choices understandable, leads each user to a stopping point, and takes the needs of actual people into account.
