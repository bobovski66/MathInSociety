1. What is a network?

A network, or graph, consists of nodes (also called vertices) and edges connecting pairs of nodes. The nodes might represent people, intersections, devices, or organizations. The edges might represent friendships, roads, communication links, or financial transactions.

To model a school communication system, draw one node for each person and connect people who can communicate directly. The resulting picture helps reveal patterns that a list of names alone would hide.

Some edges are undirected, meaning the connection works both ways. Other edges are directed, meaning that \(A\to B\) need not imply \(B\to A\). Edges can also be weighted to indicate travel time, distance, cost, or strength.

Try it. For a city map, what should a node represent? What should an edge represent? What could an edge weight mean?

2. Degree and the handshake rule

The degree of a node is the number of edges meeting it in an undirected network. A node of degree four has four direct neighbors. In a directed network, we can count incoming and outgoing edges separately.

Worked example. In a network with connections \(A-B,\ A-C,\ B-C,\ C-D\), the degrees are \(2,2,3,1\). Their sum is \(8\).

Every undirected edge contributes one to the degree of each endpoint. Consequently, the sum of all degrees equals twice the number of edges:

\[\sum \text{degree}=2m.\]

Our example has four edges, so the total degree is \(2(4)=8\). This is sometimes called the handshake rule.

Try it. An undirected network has nine edges. What is the sum of the degrees?
Check\(2(9)=18\).

3. Density describes the network as a whole

Degree describes one node. Density describes how much of the network's possible connectivity is actually present.

With \(n\) nodes, a simple undirected network can have at most \(n(n-1)/2\) edges. If it has \(m\) edges, its density is

\[D=\frac{2m}{n(n-1)}.\]

Worked example. Six nodes could have at most \(6(5)/2=15\) different undirected edges. If seven are present, \(D=7/15\approx0.467\). About 46.7% of the possible links are present.

Density close to zero means few possible connections are present. Density close to one means nearly every pair is connected directly. High density can improve the availability of alternate routes, but the location of the edges still matters.

4. Paths, distance, and connectedness

A path is a route along edges from one node to another. The length of a path in an unweighted graph is the number of edges used. A shortest path is one using as few edges as possible.

Worked example. If the connections \(A-B\), \(B-D\), and \(D-E\) exist, \(A\to B\to D\to E\) is a path of length three. If there is also a direct edge \(A-E\), the shortest path has length one.

In an undirected network, a connected component is a group of nodes that can all reach one another through paths. A network is connected if it has just one component.

In a directed network, reachability depends on direction. A message may flow from \(A\) to \(B\) without there being any permitted route back.

5. Bridges, bottlenecks, and centrality

A bridge is an edge whose removal increases the number of connected components in an undirected network. An articulation point is a node whose removal disconnects part of the network.

These are bottlenecks. If a rural town has just one road linking it to the larger highway system, closing that road can isolate the town. A second independent route creates redundancy, making the network more resilient to a single failure.

There are several meanings of a central or important node. High degree centrality means many direct connections. High closeness means relatively short paths to many other nodes. High betweenness means a node lies on many shortest paths between others.

Think about it. Could a node with just two neighbors still be extremely important for connecting two large communities? Explain why.

6. Representing a network using a table

An adjacency table records which pairs of nodes are connected. The same information can be displayed in an adjacency matrix: entry 1 means there is an edge, and entry 0 means there is not, for a simple unweighted network.

Worked example. If \(A\) and \(B\) are connected, as are \(B\) and \(C\), but \(A\) and \(C\) are not, the matrix is

\[\begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix}.\]

Notice that the matrix is symmetric for an undirected network. In a directed network, the entry from \(A\) to \(B\) can differ from the entry from \(B\) to \(A\).

A matrix is not a new network; it is another mathematical representation of the same relationships.

7. Diffusion, thresholds, and collective effects

Information, infections, rumors, and technology can move through networks. This is called diffusion. Whether something spreads depends on the network's connections and on rules governing transmission.

In a threshold model, a node may adopt an idea only after enough neighbors have adopted it. That can lead to a cascade: early changes affect neighbors, who then affect more neighbors.

Worked example. Suppose a person shares a public alert only after two neighbors have shared it. Someone with one informed neighbor waits. When another neighbor receives the alert, the threshold is reached, and that person now shares as well. The change can prompt additional sharing farther along the network.

Real diffusion is more complicated: people have different thresholds, messages can be ignored or distorted, and connections vary over time. A simple model is useful if we remember what it leaves out.

Connection to Week 5. Network diffusion can form a feedback loop: more people receive a message, more people share it, and sharing creates still more recipients. Other processes, such as fact-checking or resource limits, may damp the growth.

8. A practical method for studying a network

When investigating a network, first define the nodes and edges clearly. Next identify whether direction or weights matter. Then ask a concrete question: Who has the most direct neighbors? Can every location be reached? Which connection is vulnerable? How might a message spread?

Draw the network, check a few degrees and paths, and interpret what they mean in the original situation. The answer to “Which node matters most?” depends on what matters means in that context.

Connection to Week 10. Networks show how local connections can shape large-scale patterns. Our final week studies how simple repeated rules can likewise produce surprising patterns over time and across scales.
