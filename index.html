How grading works

  • Weekly module average: 60% of the course grade.
  • Midterm: 15%.
  • Final: 25%.
  • Within a week, Readings, Demos, Weekly Lab, Applications, and Weekly Quiz carry equal weight.
  • The current grade uses work that has been started; future untouched weeks are not counted yet.

Course sequence

The course begins with number and observation, moves through probability, statistics, information, finance, and business models, then turns those ideas into geometry, optimization, recursion, and the limits of prediction.

Using this course page

Course Help

Completing weekly work

Open the linked chapter, demo, weekly lab, application, and discussion prompt in new tabs. Return here and check “Mark complete” for the locally tracked categories. Discussion prompts are submitted through the class discussion board and are not tracked by this static page. These checkboxes are your own record; the course page does not inspect activity in another tab.

Assessment feedback

Press Check my current answers. Correct questions become locked and are saved. An incorrect response receives a small hint but not the answer. Decimal answers are accepted within a gentle tolerance, so harmless rounding differences will not block progress.

Saving progress

Course-page progress is stored in this browser using local storage. Use Export Progress to create a backup file and Import Progress to restore it on another device or browser.

Saving completed labs

Each weekly lab saves responses locally in the browser and can be printed or saved as PDF from the browser. The application pages are deliberately open-ended: they are for using the mathematics, not merely repeating a calculation.

Privacy and limitations: This static page does not send grades to an instructor or server. A printed or exported grade report can be submitted separately if required.
