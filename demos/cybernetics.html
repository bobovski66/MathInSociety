A correction can arrive too late.

Reveal the greenhouse sequences, inspect every update, and test how response strength, report age, and measurement precision affect a model.

Begin with a prediction

Use the same rule, then change one assumption

Two greenhouses begin at 64°F, have target 70°F, and correct half of the reported error each hour. One receives the current temperature; the other receives a one-hour-old report. Predict which will first pass 70. Then reveal one update at a time and use the report column to explain what happened.

In these models, a correction changes the temperature by its full computed amount in one step. We allow both warming and cooling, with no external disturbance or equipment limit. The graphs are illustrations of these rules, not equipment settings for an actual greenhouse.

Experiment 1 / The reading’s exact example

Reveal the first twelve updates

The delayed history is \(x_{-1}=x_0=64\). At step n, the correction is added to the current state \(x_n\). Only its report comes from \(x_{n-1}\).

The table lists states. The calculation above it describes the update that produced the displayed final state. Display rounding does not alter the internal updates.

  1. Show step 2. The delayed path is at the target. Predict the next correction using its available report.
  2. Show step 3, then step 4. Explain why the first adds heat and the second adds nothing.
  3. Show steps 7–12. Compare a later peak with the earlier 71.5°F peak; compare troughs as well.
Experiment 2 / Control the comparison

Change strength, delay, or the direction of feedback

Choose a preset, record its settings, then change one quantity. “Corrective” uses target minus report. “Amplifying” uses report minus reference, pushing a departure farther in the same direction. Negative values are allowed in this abstract numerical model.

Try these controlled comparisons

  • At k = 0.5, compare report ages 0 and 1, holding everything else fixed.
  • With current reports, compare k = 0.5, 1.5, 2, and 2.3. Which gaps shrink, persist, or grow?
  • Set the starting state equal to the reference. Why does the ideal model stay there?
  • For an amplifying loop, start below its reference. Does amplifying always mean “increasing”?
Experiment 3 / Precision has a timing context

How much do independent averages vary?

Assume a steady temperature and unbiased, independent readings. Individual readings have standard deviation σ. The standard deviation of an average of m readings is \(\sigma/\sqrt m\). This calculation describes repeated averages under those assumptions.

If the newest reading is current, the oldest in a consecutive batch is (m − 1) intervals old. A moving average mixes different past times; it is not identical to one perfectly accurate delayed reading. If the underlying temperature changes, the steady-state averaging assumptions need reconsideration.

Try m = 1, 4, and 16. Compare the improvement in precision with the span of time covered. Averaging does not remove a shared sensor bias.
